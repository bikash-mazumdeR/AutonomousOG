# SKILL: Bug Reporter
## Agent ID: 08-bug-reporter
## Version: 1.0.0

## Purpose
Create structured Jira bug issues and Gmail email notifications for every failed test.

## Bug Report Schema
- Title: [ENV][SEVERITY] Feature — Short description
- Description: Markdown with error, stack, environment details
- Expected Result: What should happen
- Actual Result: What actually happened
- Environment: name, browser, OS, version, baseURL
- Steps to Reproduce: Numbered steps
- Severity: Critical | High | Medium | Low
- Priority: P1 | P2 | P3 | P4
- Labels: UI, Functional, API, Performance, ARIA-AutoGenerated
- Attachments: screenshots (medium-res PNG), network logs (JSON/HAR), console logs (.log)

## Severity Inference Rules
- CRITICAL: 401, 403, 500, server error, unauthorized, forbidden
- HIGH: timeout, network failure, null pointer, ECONNREFUSED
- MEDIUM: assertion failed, element not found, locator issues
- LOW: cosmetic, minor validation

## Deduplication
Hash = MD5(title + environment + actual_result_first_100_chars)
If hash exists in Project Memory → skip Jira creation, increment occurrence count.

## Jira Fields Mapping
- Summary     → bug.title (max 255 chars)
- Description → Atlassian Document Format (ADF)
- Priority    → Highest / High / Medium / Low
- Labels      → bug.labels array
- Attachments → max 5 files per issue (screenshots priority)

## Gmail Template
- Subject: [ARIA][ENV] N Bug(s) Found — X Critical, Y High
- Body: HTML table with Jira key, TC key, title, severity, labels
- Attachments: Critical bug screenshots (max 3)
