# SKILL: K6 Performance Script Generator
## Agent ID: 05-playwright-script-generator-k6
## Version: 2.0.0
## Classification: Core — Performance & Load Test Generation

---

## 🎯 SKILL PURPOSE

Generate standalone, production-ready **K6 performance scripts** for test cases categorized as `Performance`, `Load`, `Stress`, or `Spike`.

Generates **one dedicated `.js` script per test case** under `tests/k6/{FID}-{tcKey}-perf.js`, parameterized entirely through environment variables for seamless execution in CLI and CI pipelines.

---

## 🚫 STRICT ARCHITECTURAL CONSTRAINTS

| Rule | Requirement |
|---|---|
| **K6 Native Modules Only** | Import strictly from `k6/http`, `k6`, and `k6/metrics`. |
| **NO Playwright Dependencies** | NEVER import `@playwright/test`, `test`, `expect`, or browser fixtures. |
| **Dynamic ENV Thresholds** | Rely on `__ENV` with sensible defaults; never hardcode latency thresholds or VU counts. |
| **Summary Reporting** | Export `handleSummary(data)` writing JSON metrics to `reports/json/k6-{tcKey}-summary.json`. |
| **Verified Endpoints Only** | Require proven target endpoints and SLAs; do not generate for static frontends without APIs. |

## 📐 K6 SCRIPT TEMPLATE

```javascript
/**
 * @fileoverview K6 {scenario} Performance Script — {featureName}
 * Generated by ARIA Agent 05 | TC Key: {tcKey}
 * Target Endpoint: {endpoint} | Scenario: {scenario}
 * @module {tcKey}Performance
 */

import http from 'k6/http';
import { check, sleep } from 'k6';
import { Trend, Rate } from 'k6/metrics';

// Custom metric definitions
const errorRate = new Rate('custom_error_rate');
const latencyTrend = new Trend('custom_duration_ms');

// Scenario & Threshold Options (parameterized via __ENV)
export const options = {
  scenarios: {
    {scenarioName}: {
      executor: 'constant-vus',
      vus:      parseInt(__ENV.K6_VUS, 10) || 10,
      duration: __ENV.K6_DURATION || '30s',
    },
  },
  thresholds: {
    http_req_duration: [`p(95)<${__ENV.K6_THRESHOLD_P95 || 500}`],
    http_req_failed:   ['rate<0.01'],
    custom_error_rate: ['rate<0.05'],
  },
};

const BASE_URL = __ENV.AUT_BASE_URL || 'http://localhost:3000';

export default function () {
  const url = `${BASE_URL}{endpoint}`;
  const payload = JSON.stringify({
    username: __ENV.PERF_USER || 'perf_user',
    password: __ENV.PERF_PASSWORD || 'perf_secret',
  });
  const params = {
    headers: {
      'Content-Type': 'application/json',
      Accept: 'application/json',
    },
  };

  const res = http.post(url, payload, params);

  // Assertions with check()
  const checkSuccess = check(res, {
    'status is 200':         (r) => r.status === 200,
    'response time < 500ms': (r) => r.timings.duration < 500,
    'body is non-empty':     (r) => r.body && r.body.length > 0,
  });

  // Metric tracking
  errorRate.add(!checkSuccess);
  latencyTrend.add(res.timings.duration);

  sleep(1);
}

// Summary generation for reporting pipeline
export function handleSummary(data) {
  return {
    'reports/json/k6-{tcKey}-summary.json': JSON.stringify(data, null, 2),
    stdout: `\n[K6 SUMMARY] {tcKey} completed | P95: ${data.metrics.http_req_duration ? data.metrics.http_req_duration.values['p(95)'].toFixed(2) : 'N/A'}ms\n`,
  };
}
```

## 📏 K6 EXECUTION & REPORTING RULES

1. **Standalone File Isolation:** Each performance test case produces its own self-contained file in `tests/k6/`.
2. **Environment Parameterization:**
   - `__ENV.AUT_BASE_URL` controls the target host.
   - `__ENV.K6_VUS` sets concurrent virtual users.
   - `__ENV.K6_DURATION` sets execution window (e.g. `30s`, `2m`).
   - `__ENV.K6_THRESHOLD_P95` defines 95th percentile latency threshold in milliseconds.
3. **Structured Summary Output:** `handleSummary` must output JSON formatted data to `reports/json/k6-{tcKey}-summary.json` for Agent 08 (Report Generator) aggregation.
