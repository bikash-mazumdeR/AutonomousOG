# Profile Photo Upload — Requirements

## User Story

**As a** community member **I want to** upload a profile photo **so that** other members recognise me.

## Acceptance Criteria

- AC-1: The profile page has an **Upload photo** button.
- AC-2: Only JPG and PNG files are accepted.
- AC-3: A file larger than the maximum size shows the error `File is too large`.
- AC-4: After a successful upload the new photo replaces the old one on the profile page.
